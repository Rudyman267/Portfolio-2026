# Frontend Guidelines

## 1. Component Structure

- All components should be self-contained and have a clear purpose.
- Use proper component naming conventions (e.g., `Button`, `Input`, `Modal`).
- Implement proper component props and types.
- Use proper component lifecycle methods.
- Use proper component state management.
- Use proper component event handling.
- Use proper component styling.
- Use proper component testing.

## 2. Icon Usage

- We have fontawesome icons set up in the project.
- Use the `<i></i>` tag to add icons with the class `fa-(KIT_NAME) fa-(ICON_NAME)`.
- Available KIT_NAME: `fa-regular`, `fa-solid`, `fa-kit`. `fa-kit` is our custom kit.
- List of available icons in the custom kit is available in `docs/fontawesome-icons.doc.md`

## 3. Styling

- Use Tailwind CSS for styling.
- Refer to `docs/` for more information.

### For all external libraries - 
Zustand, TanStack Query,  etc. use the documentation from the references section in `docs/004-references/third-party-library-usage/`
