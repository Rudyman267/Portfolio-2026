**Purpose**: Centralized knowledge base for team-wide learnings, best practices, and architectural decisions

## How to Use This Document

This document captures valuable technical learnings from development sessions that have broad applicability across the Flytbase monorepo. It serves as:

- **Knowledge Repository**: Preserve insights that would otherwise be lost
- **Onboarding Resource**: Help new team members understand evolved practices
- **Decision Reference**: Document why we chose certain approaches
- **Pattern Library**: Reusable patterns and solutions

**Contribution Guidelines**:

- Learnings are automatically curated from session work via `/finalize` command
- Each entry should have context, the learning itself, and rationale
- Include code examples where helpful
- Cross-reference related documentation (ADRs, feature docs)
- Keep entries concise but actionable
