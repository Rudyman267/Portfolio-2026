# START HERE — every session

**Before doing anything else, read [PROJECT_LOG.md](PROJECT_LOG.md).**
It is the persistent cross-session context: project overview, locked decisions,
environment gotchas, architecture, current state, and next steps. Do not ask the
user to re-explain the project — the log has it.

At the **end** of a session, when the user says "update the log", refresh the
**Current State**, **Next Steps**, and append a new dated **Session History** entry
in PROJECT_LOG.md.
